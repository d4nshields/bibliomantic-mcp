# bibliomantic-mcp

A local, offline [MCP](https://modelcontextprotocol.io) server that consults the *I Ching*
with the traditional three-coin method and returns the canonical text. The server casts and
retrieves; the host model interprets.

> For reflection and creativity, not prediction and not advice.

Work in progress: see `docs/BRIEF.md` for the specification.

## Run

```console
uv run bibliomantic-mcp            # stdio (default)
```
